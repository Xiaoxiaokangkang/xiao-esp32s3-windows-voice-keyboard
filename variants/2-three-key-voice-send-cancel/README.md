# V2：三键语音输入、发送、取消

- K1（D2/GPIO3）：按住语音输入，松开结束。
- K2（D1/GPIO2）：短按发送 Enter。
- K3（D0/GPIO1）：长按约 1.5 秒发送 `Ctrl+A`、`Backspace`，清空当前输入框；每次按住只触发一次。

请先松开 K1，再操作 K2 或 K3。这样可以避免语音快捷键修饰键与发送/取消动作重叠。

本目录目前只发布源码。代码以已验证的 V1 USB 音频实现为基础新增三键状态机，但尚未在本机 ESP-IDF 环境重新编译或在目标硬件上验证，因此不附带预编译镜像。构建步骤见仓库根目录 `docs/BUILDING.md`。
