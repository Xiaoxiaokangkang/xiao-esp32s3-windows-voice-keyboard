# 隐私说明

## 公开内容包含什么

- ESP32-S3 固件源码；
- V1 已验证的预编译固件；
- Windows 本地辅助脚本；
- 构建、刷写、测试和故障排查文档。

## 明确不应提交的内容

- 密码、API Token、Cookie、会话信息和账号凭据；
- 代码签名私钥、SSH 私钥、证书私钥和密钥库；
- 个人日志、录音、测试语料和聊天内容；
- 私人配置、Wi-Fi 凭据和个人绝对路径；
- ESP-IDF 的本地构建目录、缓存和临时文件；
- 未经检查的原始 ZIP、整机备份或用户目录副本。

根目录 `.gitignore` 会拦截常见敏感文件名和本地生成物，但它不能替代提交前人工检查。

## 运行时边界

固件通过 USB 向当前电脑提供键盘事件和麦克风音频，不包含 Wi-Fi 配置，不连接服务器。V3 助手只在本机监听 F13 并控制 TraeWork CN 窗口，不读取聊天内容或上传数据。
